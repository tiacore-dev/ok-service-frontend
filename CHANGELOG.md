# Changelog

## 2026-11-06

- Исправлен выбор секретов Firebase при сборке образа для dev, stage и production.
- Добавлена остановка Docker-сборки при отсутствующих или пустых настройках Firebase.

## 2026-10-27

- Обновлён Dockerfile: добавлена отдельная build/runtime-сборка, runtime-контейнер запускается от непривилегированного пользователя `node`.
- Внутренний порт frontend-контейнера изменён с `80` на `3000`; Compose-маршрутизация синхронизирована.
- Добавлены production-настройки окружения и healthcheck контейнера. Миграции базы данных и изменения API отсутствуют.
